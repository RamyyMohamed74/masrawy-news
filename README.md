# Ezzoo Birthday Invitation 🎂

A mobile-friendly birthday invitation made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — invitation content
- `style.css` — design and animations
- `script.js` — countdown, music and confetti
- `assets/ezzoo.jpg` — birthday photo
- `assets/birthday-music.wav` — original simple birthday-style instrumental

## Publish it for free with GitHub Pages
1. Create a GitHub repository, for example `ezzoo-birthday`.
2. Upload all files while keeping the `assets` folder.
3. Open the repository's **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will give you a public URL that you can send on WhatsApp.

The invitation is static, so no server or database is required.
